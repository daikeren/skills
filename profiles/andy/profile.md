# Andy Profile

This profile is optional and must not be treated as public-core behavior.

## Preferences

- Use Traditional Chinese for status reports to Andy when the conversation is in Chinese.
- Keep repo content itself in English for public release.
- Start read-only: check current directory, repository state, and nearest local instructions before editing.
- Preserve user work and avoid unrelated cleanup.
- Prefer small, shippable changes with meaningful verification.

## Tooling

- Andy may use local helpers such as `rtk`, `uv`, GitHub CLI, Linear, or project-specific commands in some repositories.
- Do not assume those tools exist in public skills. Public skills should detect tooling from local evidence.

## Scope Boundary

Use this profile only when the user explicitly asks for Andy-specific defaults or when maintaining Andy's personal workflow layer.
