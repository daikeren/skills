# Generic Profile

Use this profile as the public default.

## Defaults

- Start read-only and discover local instructions before editing.
- Detect tools from the repository instead of assuming a stack.
- Prefer small, reversible implementation slices.
- Treat product, architecture, security/privacy, operations, cost, and team speed as first-class constraints.
- Use local docs and CI as the source of truth for verification.

## Non-Defaults

- Do not assume GitHub, Linear, Jira, Slack, Notion, Django, Next.js, uv, rtk, npm, pnpm, Bun, or any monorepo layout.
- Do not write organization-specific policy into the public core.
- Do not create tickets or external artifacts unless the user asks or the local workflow requires it.
